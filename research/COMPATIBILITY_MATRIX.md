# Compatibility matrix

Status words: **supported** = converted and exercised by tests; **partial** = converted with a documented difference; **unsupported** = reported, not converted; **n/a** = not applicable.
Claims are limited to what the test fixtures in `testdata/` exercise. Nothing was validated against a licensed LoadRunner install or a running JMeter.

| Area | JMeter 5.6 import | JMeter export | LoadRunner VuGen (Web) | HAR 1.2 |
|---|---|---|---|---|
| HTTP requests, headers, query, form, JSON body | supported | supported | supported (`web_url`, `web_custom_request`, `web_submit_data`) | supported |
| Multipart upload | supported | supported | partial | supported |
| Cookies | supported (Cookie Manager) | supported | supported (auto) | supported (per-VU jar) |
| Transactions | supported (Transaction Controller) | supported | supported (`lr_start/end_transaction`) | generated by page/time gap |
| Think time | supported (timers) | supported | supported (`lr_think_time`) | generated from gaps |
| Loops | Loop, ForEach, Runtime supported; While partial (capped, unresolved = false) | supported | `for`/`while` unsupported | n/a |
| Conditions | If (simple) supported, complex partial | supported (`__jexl3`) | unsupported | n/a |
| Mix / sync controllers | Switch, Throughput, Interleave, Random, Random Order, Critical Section, Constant Throughput and Synchronizing timers supported | supported | unsupported | n/a |
| Extractors | Regex, JSON, Boundary supported; XPath partial | jsonpath/regex/boundary supported; xpath/cookie partial | `web_reg_save_param(_ex/_json/_regexp)` supported | via correlation |
| Assertions | Response/JSON/Duration supported; negations partial | supported; header partial | `web_reg_find` supported | status assertions generated |
| Data files | CSV Data Set supported | supported (inline rows need a companion CSV) | `.prm` + `.dat` supported (partial key coverage) | parameterization generates CSV |
| Workload | Thread Group, Ultimate/Concurrency TG (partial) | closed model supported; arrival-rate partial | run-time settings partial | n/a |
| Functions | common `__` functions mapped; others reported | mapped back | `lr_eval_string`, `{param}` supported | n/a |
| Scripts (JSR223, BeanShell, C) | unsupported (reported with excerpt) | n/a | unsupported | n/a |
| Non-HTTP protocols | unsupported | n/a | unsupported (needs licensed runtime) | n/a |
| SLAs / pass-fail | n/a | unsupported (no JMeter equivalent) | n/a | n/a |

Details: `internal/jmx/SUPPORT_MATRIX.md`, `internal/loadrunner/README.md`, `internal/har/har.go`.
Every import prints an itemised report (one entry per element) with a confidence score; nothing is dropped silently.
